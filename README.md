‌What is this?‌
This is a lightweight Tampermonkey userscript that swaps GeoFS's default map tiles for crisp, high-resolution ArcGIS World Imagery satellite imagery. Say goodbye to blurry default terrain and hello to actually being able to see rivers, runways, and small towns from altitude. No more "am I flying over a field or a lake?" moments. 🗺️✨

How to use it

copy the code,

Launch GeoFS like normal, if you are on a computer press F12 to open the ‌Browser Developer Tools‌ 
paste the code you just coppied  

the map will automatically switch to ArcGIS

Hit the ‌D key‌ any time to pull up the control panel (ESC closes it too)

The panel is draggable, drag it wherever it doesn't block your instruments

Cool features
‌
3 fallback ArcGIS servers‌ — if one node goes down, it automatically tries the next one so you don't lose your map mid-flight

One-click map reload for when tiles get stuck loading

Built-in cache cleaner to fix blurry tiles and free up browser memory

Real-time tile counter shows how many tiles are rendering/loading

Toast notifications for every action — you always know what's happening

Built-in help panel with troubleshooting tips

100% free and open source (GPL-3.0 license), no paywalls, no sketchy ads

Works offline once tiles are cached! Perfect for long hauls with spotty internet
No external dependencies, runs entirely in your browser
